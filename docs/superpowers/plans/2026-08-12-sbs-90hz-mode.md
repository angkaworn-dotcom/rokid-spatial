# SBS 90 Hz Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An opt-in Station-2-style mode: panel mode 4 (3840×1200 @ 90 Hz SBS), stereo per-eye rendering with live IPD, a 1920×1200 @ 90 Hz virtual display as the working desktop, standalone (no-mirror) arrangement, and watchdogs that defend that arrangement instead of fighting it.

**Architecture:** SBS-90 is a variant of the existing `.glassesOnly` source, keyed on a new persisted `sbs90` toggle. This deliberately inherits every glasses-only behaviour that still applies (brightness dim, kiosk-level overlay, rendered cursor, no stranded-apps check). The differences — panel mode 4 instead of 0, capture a 90 Hz virtual display instead of the glasses' own desktop, `stereo = true`, standalone instead of mirrored, 90 fps instead of 60 — all branch on one computed `sbsActive` property.

**Tech Stack:** Swift / AppKit / Metal / ScreenCaptureKit / CGVirtualDisplay (private) / libusb. Build with `swift build`; install with `./Scripts/make-app.sh` (cert `RokidSpatial Dev`, never ad-hoc).

## Global Constraints

- **60 Hz mode-0 stays the default**; SBS-90 is strictly opt-in.
- **Frames must not fall below 60** (user requirement, verified via `pacing:` log lines).
- **Main screen always centred**; wall-layout watchdog enforces it.
- **Multi-screen is anchor-only** (already enforced; do not relax).
- **No mirror set anywhere while SBS-90 runs** — macOS harmonizes a mirror set's flip rate down to its 60 Hz member (proved 2026-08-12; BetterDisplay #121/#4280 concur). The `reassertGlassesOnlyMirror()` watchdog actively re-mirrors and **must be conditioned off in SBS** or it will fight the standalone arrangement.
- **Never leave the machine in a state the user can't escape** (⌃⌥Esc emergency stop must keep working; every stop path must land in the trap-free mirrored-2D state).
- **Perceptual changes: only the user's eyes decide.** Functional verification via `~/Library/Logs/RokidSpatial.log`.
- macOS re-applies remembered arrangements/modes on every reconfiguration — extend the existing defences, never bypass them.
- When scripting app restarts, wait for `pgrep -x RokidSpatial` to clear first (two instances racing tangles display state).
- No unit-test target exists and the behaviour under test is display-server + USB hardware state; each task's test cycle is `swift build` plus behavioural verification via the probe flags and the log. The final task is a live hardware protocol.
- The user writes in Thai; reply in Thai. Code and docs stay English.

## Hardware facts this plan relies on (all measured on this machine)

- Panel mode 4 = 3840×1200 @ 90 Hz, per-eye 1920×1200, desktop-usable. **Eye-tested 2026-08-12: no grey lines, sharp** ("ไม่มีเส้นนะ ชัดดี").
- In mode 4 every desktop mode macOS offers is 90 Hz; the desktop is 1920×600 *points* at 2.0 backing scale (3840×1200 px) — a 16:5 sliver, unusable as a workspace. Hence the virtual working desktop.
- Changing the panel mode makes the display re-enumerate and macOS re-applies its remembered arrangement (mirroring included) up to ~10 s later, possibly twice. Mode first, then arrangement.
- A 60 Hz virtual display in the set drags composition down even unmirrored — every virtual display must be created at 90 Hz (`VirtualDisplay.create(refreshRate:)` exists).
- `CGDisplayVendorNumber == 12372` identifies the glasses; `NSScreen` is a stale main-thread cache — `DisplayManager` already handles both.

- [ ] **Step 1: Add `prepareSBS()` after `prepareGlassesOnly` (after line ~292)**

```swift
    /// SBS-90 (Station-2-style): panel mode 4 — 3840×1200 @ 90 Hz, stereo —
    /// run *standalone*. No mirror set anywhere: macOS harmonizes a mirror
    /// set's flip rate down to its 60 Hz built-in member, which would waste
    /// the whole mode. The working desktop is a separate 90 Hz virtual
    /// display the controller creates *before* calling this — creating a
    /// display is itself a reconfiguration, and doing it afterwards would
    /// invite macOS to re-apply the remembered (mirrored) arrangement this
    /// just fought off.
    func prepareSBS() throws {
        availableDesktopSizes = []
        previousMode = try? RokidDisplay.currentMode()
        try RokidDisplay.setMode(.highRefreshRateSBS)
        Thread.sleep(forTimeInterval: 3.0)

        // The re-mirror war again. Short quiet window: the session watchdog
        // stands guard once a second from here on.
        enforceUnmirrored(timeout: 15, quiet: 4)

        // Un-mirroring re-enumerates; resolve IDs only after it.
        guard let glassesID = findGlassesDisplay() else {
            throw SetupError.glassesNotFound
        }
        glassesDisplayID = glassesID
        deskDisplayID = onlineDisplays().first { CGDisplayIsBuiltin($0) != 0 }

        // Assert the panel-native raster — the mode macOS remembers for this
        // display can be anything a past tangle left behind. Every mode-4
        // desktop mode is 90 Hz (measured), so only the size needs picking:
        // 1920×600 points at 2.0 backing = the full 3840×1200 px raster.
        setDesktopResolution(glassesID, width: 1920, height: 600)
        if let current = CGDisplayCopyDisplayMode(glassesID) {
            glassesDesktopSize = (current.width, current.height)
        }
    }
```

- [ ] **Step 2: Replace `wallLayoutIsBroken` and `fixWallLayout` (lines ~518–553)**

Replace both functions (keep the stray `@discardableResult` attribute exactly where it is) with:

```swift
    /// The wall layout: `mainID` at the origin (menu bar and centre of the
    /// wall), right side flush against its right edge, left side flush
    /// against its left, and any `parked` displays stacked directly below —
    /// reachable, but the pointer has to be pushed there deliberately.
    /// macOS's remembered arrangements scatter these on re-apply; the
    /// watchdog checks cheaply every second and fixes in one batched
    /// reconfiguration. Glasses-only passes the glasses as main; SBS-90
    /// passes the working virtual desktop as main and parks the glasses
    /// and the built-in below it.
    func wallLayoutIsBroken(main mainID: CGDirectDisplayID,
                            sides: [(id: CGDirectDisplayID, isRight: Bool)],
                            parked: [CGDirectDisplayID] = []) -> Bool {
        let main = CGDisplayBounds(mainID)
        if main.origin != .zero { return true }
        for side in sides {
            let bounds = CGDisplayBounds(side.id)
            let expectedX = side.isRight ? main.maxX : main.minX - bounds.width
            if bounds.origin.x != expectedX || bounds.origin.y != main.minY { return true }
        }
        var y = main.maxY
        for id in parked {
            let bounds = CGDisplayBounds(id)
            if bounds.origin.x != 0 || bounds.origin.y != y { return true }
            y += bounds.height
        }
        return false
    }

    func fixWallLayout(main mainID: CGDirectDisplayID,
                       sides: [(id: CGDirectDisplayID, isRight: Bool)],
                       parked: [CGDirectDisplayID] = []) {
        let mainWidth = Int32(CGDisplayPixelsWide(mainID))
        try? configure { config in
            var err = CGConfigureDisplayOrigin(config, mainID, 0, 0)
            guard err == .success else { return err }
            for side in sides {
                let width = Int32(CGDisplayPixelsWide(side.id))
                err = CGConfigureDisplayOrigin(config, side.id,
                                               side.isRight ? mainWidth : -width, 0)
                guard err == .success else { return err }
            }
            var y = Int32(CGDisplayPixelsHigh(mainID))
            for id in parked {
                err = CGConfigureDisplayOrigin(config, id, 0, y)
                guard err == .success else { return err }
                y += Int32(CGDisplayPixelsHigh(id))
            }
            return .success
        }
        Thread.sleep(forTimeInterval: 0.5)
        // Every reconfiguration invites a remembered-mode re-apply too.
        reapplyDesktopSize()
    }
```

(Note: `CGDisplayBounds` and `CGDisplayPixelsWide/High` both report *points* on hiDPI displays despite the latter's name — the existing code already mixes them this way, e.g. `arrangeStandalone`. Stay consistent.)

```swift

            // Modes that must stay unmirrored (extended sources, SBS-90)
            // treat any mirror set as a fault to undo; plain glasses-only
            // treats the mirror as the desired state. SBS must never
            // re-mirror: a mirror set harmonizes its flip rate down to the
            // 60 Hz built-in member and the 90 Hz mode is wasted.

                        .compactMap { $0 }.filter { $0 != mainID }

                   displays.wallLayoutIsBroken(main: mainID, sides: sides, parked: parked) {

                    Self.appendLog("layout: the wall drifted — recentring the main screen")

                            displays.fixWallLayout(main: mainID, sides: sides, parked: parked)
```
